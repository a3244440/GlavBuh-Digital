# Калькулятор — корпоративный прайс с фотографий пользователя

Источник: две фотографии прайса филиалов г. Астана, присланные владельцем 15.10.2026. Они заменяют прежние тарифы калькулятора с сайта. ИП/ТОО остаётся частью профиля, но в новом прайсе форма организации не меняет цену.

Суммируются выбранная база и применимые доплаты, затем +10% к общей сумме. Скидка консультанта включается отдельно: −10% от суммы с наценкой. Итого при скидке 99% исходного расчёта. Денежные операции округляются до тенге.

Трактовки, явно показанные клиенту и отправленные владельцу на уточнение: сотрудники с первой начатой группы из 5; превышение лимита — разовые +20 000 для каждой категории, не за каждый последующий блок; смешанная деятельность по тарифу товаров; импорт+экспорт одна общая доплата. В прайсе не указано другое правило. При ответе владельца заменить эти правила и граничные тесты. Общее число первичных документов сохраняется для консультации, но не подменяет три показателя с разными периодами.

Восстановление по фото: от 150 000 за проект. Формулы по месяцам/состоянию нет; калькулятор показывает только минимум с наценкой/скидкой и сохраняет период и объём для консультации. Месячные доплаты в проектную сумму не добавляются. Отдельные услуги из фото — возврат НДС разово 150 000, баланс от 100 000/год — не смешиваются с месячным тарифом. Пакеты Light (30 000) и Хостинг (15 000) прямо обозначены как услуги 1С без бухгалтерского и налогового учёта: не предлагаются вместо ведения/восстановления бухгалтерии.

Формула: public/pricing.js. Интерфейс /calculator/. Расчёт копируется или переносится в заявку, при подключённом Telegram отправляется вместе с обращением. Секция скидки публична, только моделирует предложение, право на скидку подтверждает консультант. Расчёт не является доверенной ценой для оплаты.

Страница /price-list/ пока сохраняет исходный веб-прайс для миграции и может отличаться: для новой формулы источник — предоставленные фото. В интерфейсе калькулятора ставки показаны прямо у полей и в расшифровке.
